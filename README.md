# Fuse Tool Box
一个PC端pyside6的桌面工具箱，功能正在陆续完善中
最新版本  V1.0.5
## 已有功能
- **图片处理**：
  - 批量生成封面
  - 图片拼图-横向和纵向拼图
  - 批量缩放图片
  - 批量图片OCR
  - 批量转换格式
  - 表格截图转成Excel
- **PDF处理**：
  - PDF拆分
  - PDF合并
  - PDF提取
  - PDF批量转图片
- **文件名处理**：
  - 批量重命名
- **编号生成**： 
  - 按规则生成指定格式的编号


## 环境要求
- 我的python版本是 3.11.9 其他版本请自测
- 依赖库见 `requirements.txt`

## 安装依赖库

```bash
pip install -r requirements.txt
```
## 使用
运行主程序：

```bash
python main.py
```

## 说明
- main.py 是程序入口，运行后启动主窗口。
- Ui_main.py 定义启动后的窗口样式。
- menus.py 负责左侧菜单的配置。
- pages/ 下每个子目录对应一个功能模块，包含页面样式和具体逻辑。
- yulu.txt 中的语录会在程序主页面随机展示。
